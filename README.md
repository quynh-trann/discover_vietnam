## Notes

One challenge I faced during this project was setting up the connection between the frontend and backend. I initially ran into issues with API requests, routing, and loading data correctly from the Express server. I also had trouble configuring Vite and handling errors when navigating to the detail pages. Through debugging the browser console, checking routes, and testing API endpoints, I was able to identify the problems and fix them. This project helped me better understand how frontend and backend components communicate in a full-stack web application.

## Notes

The most challenging part of this project was setting up the PostgreSQL database and connecting it to my existing application. I encountered errors with environment variables, database seeding, and displaying the correct data from the database. It took several rounds of debugging to figure out why only some records were appearing and why certain fields and images were missing. Although it was frustrating at times, I learned a lot about working with databases and integrating a backend with a frontend application.
